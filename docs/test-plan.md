# План дальнейших тестов

Исследование остановлено. Этот список предназначен для будущей работы; перечисленные действия не выполнялись после остановки.

## Критерий успеха

Несколько последовательных запусков с входом на сервер, отображением мира и интерфейса, управлением персонажем и нормальным выходом. Для этого проекта разовое меню или сообщение об успешной авторизации недостаточно.

## Следующий опыт

1. Сохранить чистый префикс и точные версии всех компонентов.
2. Повторить ранний сбой PortProton с подробным журналом Wine: найти непосредственное необработанное исключение или код завершения.
3. Проверить локализацию как отдельную гипотезу, сохранив исходник и сравнив контрольные суммы после проверки лаунчером. Остановка лога на `client.pot` сама по себе не доказывает причину.
4. При успешном старте отдельно сравнить чистый оконный и полноэкранный режимы, сначала на одном мониторе. Зафиксировать DXVK, разрешение и браузерные настройки.
5. Если снова появляется serial-validation, собрать обезличенные сведения об окружении и свериться с актуальной официальной документацией MTA. Не подменять идентификаторы и не обходить защиту.
6. Только после стабильного входа проверять Full HD, русскую раскладку, удержание курсора и повторные запуски.
