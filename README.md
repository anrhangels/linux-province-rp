# linux-province-rp

**MTA Province на Linux · технический отчёт о совместимости**

> **Стабильной игры добиться не удалось.** В отдельном 32-битном окружении один раз удалось войти на сервер, но экран мерцал, мир и интерфейс работали некорректно, управление персонажем не было подтверждено. Последующие попытки сопровождались ошибками проверки серийного номера или завершались на раннем запуске. Готового рабочего решения нет.

Проверки проходили **6–7 ноября 2026 года**. Исследование остановлено 7 ноября по решению автора. Репозиторий сохраняет результаты для тех, кто захочет продолжить диагностику. При оформлении документации новых игровых тестов не проводилось.

## Что получилось

| Этап | Итог |
| --- | --- |
| Установка официального Windows-лаунчера | Выполнена |
| Обновление лаунчера и загрузка игры | Подтверждены, но загрузка была долгой и зависела от сети |
| GE-Proton 11-11 через Faugus / UMU | Зависание при подключении |
| Caffe 9.7, чистый 32-битный префикс | Один вход на сервер; мерцание, неполный интерфейс, затем serial-validation |
| Нативный сервер MTA от root | Запускался; ошибку serial-validation не устранил |
| PortProton Flatpak, GE-Proton 11-11, стабильный DXVK | Лаунчер работал; клиент завершался до подключения |
| Full HD | Режим 1920×1080 подтверждён в одном из запусков; стабильность не достигнута |
| Полноценная игра | Не подтверждена |

Ошибка `libwow64.dll`, исключения в сетевом модуле и проверка серийного номера **не доказывают блокировку античитом**. Единую причину установить не удалось.

Через Git:

Или [скачайте ZIP](https://github.com/anrhangels/linux-province-rp/archive/refs/heads/main.zip) и распакуйте его. README и документы также можно читать прямо на GitHub без скачивания.

## Файлы и установка

Здесь опубликована документация. Рабочего автоматического установщика, готового префикса, DLL, файлов игры и исправления Wine нет. Экспериментальные локальные команды не выдаются за готовое решение.

Сырые журналы, дампы, данные аккаунтов и идентификаторы оборудования не опубликованы. Локальные установки и журналы при завершении исследования не удалялись. Подробные трассировки к отчёту не приложены, поэтому выводы требуют проверки на новых опытах.
